# SQL deliverables

Create and save the following SQL files in this folder:

- `schema.sql` — create the date, product, customer, and store dimensions and the line-grain sales fact table. Define primary keys, unique business keys, foreign keys, and suitable checks.
- `sales_by_month_category.sql` — aggregate completed net sales and units by calendar month and product category.
- `sales_by_region.sql` — aggregate completed net sales and count distinct completed orders by store region.
- `order_value_summary.sql` — calculate total completed net sales, distinct completed order count, and average order value.

Use explicit joins and labels. Explain in `docs/design_record.md` how each join follows from the table grain and key relationships.
